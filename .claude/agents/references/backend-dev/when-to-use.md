## When to Use This Agent

Use this agent when:

- `contract.md` is final and gates 3c/3d have passed (team flow step 4)
- Review or QA sent back blockers/bugs owned by BE

Do not use this agent when:

- The work is in files FE or devops own
- The contract itself needs to change (send to architect)
- The task is merging, pushing or deploying
