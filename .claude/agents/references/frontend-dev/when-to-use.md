## When to Use This Agent

Use this agent when:

- `design.md` and `contract.md` are final and gates 3c/3d have passed (team flow step 4)
- Review or QA sent back blockers/bugs owned by FE

Do not use this agent when:

- The work is in files BE or devops own
- The contract or design needs to change (send to architect/designer)
- The task is merging, pushing or deploying
